## Overview

This workshop introduces participants to the command line and basic shell scripting, providing essential skills for working with research data, high-performance computing (HPC) systems, cloud environments, and bioinformatics workflows.

Participants learn how to navigate file systems, manage files and directories, run commands efficiently, and automate repetitive tasks. The workshop emphasises practical, hands-on exercises that build confidence in working outside graphical interfaces.

By the end of the workshop, participants will be able to use the command line to organise data, execute programs, and work more effectively in computational research environments.

## Audience

PhD students, researchers, research support staff, and others who need to work with computational tools, research software, HPC systems, or large datasets. No prior command-line experience is assumed.

## Learning objectives

Participants will learn how to:

* Open and use a Unix/Linux shell
* Navigate file systems using relative and absolute paths
* Create, copy, move, rename, and delete files and directories
* View and edit text files from the command line
* Use wildcards and tab completion efficiently
* Redirect input and output between commands and files
* Combine commands using pipes
* Search and filter text data using common command-line utilities
* Write simple shell scripts to automate repetitive tasks
* Understand how command-line skills support reproducible and scalable research workflows
